# Process analysis reports

This branch is a shared inbox for analysis requested from Process 1, Process 2, and Process 3.

## Rules

- Add a new Markdown file under `process-reports/` for each answer. Use a unique name such as `2026-10-21-process3-pcode-recursion.md`; do not overwrite another process's report.
- Include the question and the relevant code/evidence inline so the report remains useful without access to a chat or a local file path.
- Separate facts from inferences. Cite exact function addresses, source/artifact paths, hashes, and line numbers when available; state uncertainty and what the evidence does not establish.
- Keep this branch report-only. Do not change runtime, renderer, or other source files here.
- Commit each report to this branch. If GitHub write access is unavailable in your chat, return the complete report in chat and say that the commit could not be made.

The branch starts from `main`. Reports are evidence for review; they are not automatically merged into `main` or treated as code changes.
