# Process 2 — P1-facing D3D9 packet adapter acceptance (2026-10-21)

**Scope:** static, GitHub-only review of the first *future* retail-derived P-code guest `IDirect3DDevice9::DrawIndexedPrimitive` packet and its admission to the existing offline Vulkan replay. No source edits, no PR edits, no local binary/log execution. The requested report is the only repository change.

## Executive verdict and frontier

**The P1 packet-v1 ABI and existing P2 adapter suffice to receive and persist a qualifying first indexed guest draw as offline `SHIFT.D3D9RuntimeCaptureSchema/1`. They do not, by themselves, prove render-ready Vulkan replay of that new packet.** P2 replay of a *different*, previously externally captured retail D3D9 draw is established by merged [PR #2139](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/pull/2139), not by the P1 callback.

The supplied bounded v691 evidence uses original PE32 SHIFT.exe retail PC 1.02 SHA-256 `eca479aa2d8dbb88bc55709d91ae5c7159ae1b00fc9555d6701000c26de8aee1` under the **integrated recompiled guest P-code host-frame replay**, **not a native retail game launch**: 360 host frames; 1,741,414 P-code dispatches; 4,729 functions; validation errors 0; blocker null; `guest_draw_translation=false`; `retail_rendering_proven=false`; **no guest Draw packet**. Host-frame, dispatch, Clear/Present, or validation counts do **not** establish game/menu/race rendering or a packet callback.

GitHub state at review: P1 [PR #2140](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/pull/2140) is **draft/open**, head `9281669ee3e7b547abd6afcbdf557d2d3561671a`. P2 capture adapter [PR #2141](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/pull/2141) is **merged** into its target branch, head `9d9db201dd677f2f8d3eb811a6d475c8e176222a`. P1's checked-in integration adapter is an **earlier code variant**, not bit-identical to #2141 head (see below). The separate #2143 capability and #2144 texture decoder/resource PRs are open and outside this review.

## 1. Exact contract and responsibility boundary

**P1 producer** — [`native_runtime/src/recompiled_pcode_module.cpp` `d3d9_device_draw_indexed_primitive()` lines ~7149–7433](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/blob/9281669ee3e7b547abd6afcbdf557d2d3561671a/native_runtime/src/recompiled_pcode_module.cpp#L7149-L7433). Reads **seven 32-bit stack arguments**: device/this, primitive_type, base_vertex_index (signed bit pattern), min_vertex_index, num_vertices, start_index, primitive_count. Before entering P2 it requires:

- Recognized device pointer and `scene_active=true`; `primitive_type ∈ [2,6]` (point list unsupported); bound IB.
- Non-null `guest_d3d9_adapter_info.draw_indexed_primitive` callback. IB object belongs to this device and is unlocked. Every bound VB/texture belongs to the device and is unlocked; declaration, VS, PS objects, if referenced, must be valid and match their expected type.
- Guest-owned textures have present, addressable, sized managed mip storage; the producer computes mip layout and copies **actual guest bytes**, rejecting invalid pointers, overflows and size mismatches. It collects 16 stream bindings/frequencies, IB metadata, declaration elements, VS/PS tokens, exact shader DWORD constant banks and masks, textures, render/sampler states, viewport, render-target and depth descriptors and last-clear parameters. The handler does **not** manufacture P2 bytes on failure.

**P1 stops at this synchronous call** (same file ~7421):

```cpp
guest_d3d9_adapter_info.draw_indexed_primitive(
    guest_d3d9_adapter_info.backend_context, packet, callback_error);
```

If the callback returns false, P1 propagates its message and returns `D3DERR_NOTAVAILABLE`. P1 successful HRESULT means accepted callback/forwarding contract, **not** native Vulkan submission. P1 owns accurate guest execution/handler dispatch, object identity/lifetime, buffer updates, guest snapshot semantics, state, and proof of target/time of the last Clear.

**Shared ABI** — [`native_runtime/include/shift_recompiled_pcode_module.hpp` lines 202–330](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/blob/9281669ee3e7b547abd6afcbdf557d2d3561671a/native_runtime/include/shift_recompiled_pcode_module.hpp#L202-L330):

- `RecompiledGuestD3d9DrawIndexedPrimitivePacket`, default `version=1`; scalars `guest_device`, `sequence`, `primitive_type`, `base_vertex_index`, `min_vertex_index`, `num_vertices`, `start_index`, `primitive_count`.
- `streams[16]` entries: `guest_buffer`, `offset`, `stride`, `frequency`, `size`, `usage`, `fvf`, `pool`.
- `guest_index_buffer` plus `index_buffer_{size,usage,format,pool}`; `guest_vertex_declaration` and `vertex_declaration_elements` (DWORD pairs); VS/PS object pointers and `vertex_shader_tokens`/`pixel_shader_tokens`.
- `vertex_float_constants[256*4]`, `pixel_float_constants[224*4]`, per-stage `float_constant_set_mask[8]`; `vertex_bool_constants[16]`, `pixel_bool_constants[16]`, per-stage `bool_constant_set_mask` (DWORD). These are **raw DWORD values**, with bits marking only values proved set via guest APIs; do not infer missing writes.
- `textures`: each `stage`, `guest_texture`, `width`, `height`, `levels`, `usage`, `format`, `pool`, `pitch`, `backend_owned`, and `mip_data` vector (`width,height,pitch,bytes` per mip). `render_states`, `sampler_states`: triples `object,state,value`. `viewport[6]` raw DWORDs; `render_targets` (index, guest_surface, eight descriptor DWORDs), optional `depth_surface`; `last_clear_{flags,color,depth_bits,stencil,rect_count}`.
- Callback signature: `bool (*)(void* context, const RecompiledGuestD3d9DrawIndexedPrimitivePacket&, std::string& error)`; packet/vector references are **only valid synchronously during callback**.

**P2 consumer starts at** `D3d9PacketCaptureAdapter::draw_indexed_primitive_callback`, then `capture_draw`, then optional `forward_draw`. P1 wires it when nonempty `SHIFT_D3D9_PACKET_CAPTURE_DIR` is set in [`native_runtime/src/shift_runtime.cpp` ~2271–2285](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/blob/9281669ee3e7b547abd6afcbdf557d2d3561671a/native_runtime/src/shift_runtime.cpp#L2271-L2285). P2's `install` wraps create/update/release VB/IB, create/release texture, create-device, Clear, Present, and DIP hooks; it retains the previous downstream context. Default capture `draw_limit=1`. The wrapper creates a per-packet directory `draw_<guest_device_hex>_<sequence>/` with `capture.jsonl` and `buffers/*.bin` and `textures/*_s<stage>.dds`, `event_index` local to capture; `guest_draw_sequence` remains an independent field. `frame=0` is **synthetic local packet framing**, not the retail frame. This is `SHIFT.D3D9RuntimeCaptureSchema/1`, an *offline capture input*, not Vulkan submission.

## 2. P2 capture admission and fail-closed conditions

**Current P1-integration adapter source**: [`native_vulkan/src/d3d9_packet_capture_adapter.cpp` lines ~380–946](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/blob/9281669ee3e7b547abd6afcbdf557d2d3561671a/native_vulkan/src/d3d9_packet_capture_adapter.cpp#L380-L946), blob `3f993d555be5b8e6861a32534b59609580c82f65`.

- `install` fails on a second installation, empty output root, or zero draw limit; a null callback context fails. Downstream resource callback failure propagates; missing downstream draw callback is **not** an error (`forward_draw` returns true) and does **not** mean a GPU draw.
- `capture_draw`: `packet.version == 1`; **nonzero** `guest_device`, `guest_index_buffer`, `guest_vertex_declaration`, `guest_vertex_shader`, `guest_pixel_shader`; **nonempty** `vertex_declaration_elements`, VS/PS token arrays. Missing any rejects. These checks are stricter than some legal D3D9 configurations (e.g. null shaders) and must not be bypassed by fabricating a guest binding.
- Registered IB identity/device and `size,usage,format,pool` must match a prior wrapped `create_index_buffer` callback. Every **bound** stream has `stride>0`, and its VB identity/device and `size,usage,fvf,pool` must match `create_vertex_buffer`. IDs cannot be reused without release. Buffer descriptors require nonzero IDs/device, nonzero size, size ≤256 MiB; update data must be non-null when size>0, and offset/length within allocation.
- **Every byte** in complete IB and bound VB snapshots must have arrived through `update_*_buffer` callbacks. If a buffer is dynamic (`usage & 0x200`) and its update was partial, callback lacks `D3DLOCK` flags: adapter sets `has_unproven_discard_semantics` and fails `dynamic ... buffer had partial updates without lock flags; discard state is unknown`. Missing byte coverage rejects. Neither cached bytes nor a replay generation may be synthesized.
- Each texture binding: current P1-integrated adapter permits only `stage<=15`; if `backend_owned=false`, `dds_bytes` demands nonzero dimensions, positive levels matching number of mip entries, supported texture format (A8R8G8B8/A1R5G5B5/BC1/BC2/BC3), successive halved mip dimensions, nonzero pitch at least block/row minimum, and exactly `mip.pitch * row_count` bytes. Backend-owned texture **must have no guest mip payload** and retains `snapshot_status=backend-owned`. It cannot satisfy an active sampler needing real pixel bytes.
- `emit_float_constant_events` emits only set-mask registers; any emitted non-finite IEEE float is rejected because the JSON schema represents both `values` and exact `values_bits`. `json_float` also rejects non-finite viewport/clear depth. File open/write/close/rename failures reject. Partial `.tmp` output is removed and the error is returned to P1; no successful capture increment.
- The P1-integration adapter serializes raw draw args, stream frequencies, float/BOOL DWORD banks and masks, declarations, shader tokens, full VB/IB byte payloads, DDS snapshots, render/sampler states, viewport, target/depth descriptor and an event derived from `last_clear`. Its one-first-draw limit stops subsequent captures, not guest callback dispatch.

**Exact variant warning:** merged #2141 **head** `9d9db201...` has [a later adapter implementation](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/blob/9d9db201dd677f2f8d3eb811a6d475c8e176222a/native_vulkan/src/d3d9_packet_capture_adapter.cpp) (blob `2b7b43aa72239336813238aaa37fd77fd610585a`) that keeps source vector ordering, permits `SetTexture` stages 0–259 (including vertex texture slots 256–259), preserves exact top mip pitch, bounds guest texture snapshot to 64 MiB and full mip-count, and labels synthesized last-Clear state **unproven**. These changes are **not** present in current P1 branch adapter blob; reporting HEAD #2141 behavior as already installed in P1 would be incorrect. Both are packet-v1 consumers; packet.version alone is insufficient evidence that independently built ABIs/code paths match. Build with the same current P1 public header.

## 3. Separate, stronger Vulkan replay admission (not an automatic consequence of capture)

Existing builder: [`src/render/vulkan/vulkan_d3d9_capture_bundle.py::build_vulkan_capture_bundle(capture,event_index,output_dir)`](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/blob/9d9db201dd677f2f8d3eb811a6d475c8e176222a/src/render/vulkan/vulkan_d3d9_capture_bundle.py#L928-L1302). It accepts `capture.jsonl` and the **JSONL `event_index` of `draw_indexed_primitive`**, not `packet.sequence`, and produces `SHIFT.D3D9CaptureVulkanBundle/1` components: geometry `geometry.svpk`, shader SPIR-V, `constants.svcp`, optional `textures.svtp`, `pipeline_state.json`, `render_target.json`, `draw_evidence.json`, `native_submission_gate.json`. Existing native executor `native_vulkan/src/vulkan_bundle_execute.cpp` on `main` consumes the bundle and supports `<bundle_dir> [output.ppm] [--validation]`.

Builder must fail closed when any of the following is unproven or unsupported:

- `primitive_type != 4` (only triangle lists), `index_buffer_format != 101` (INDEX16); missing indexed stream/create/update range, invalid start/index count, out-of-bounds effective vertex range, unsupported vertex declaration/semantic or shader opcode, invalid source attribute/stride/ranges, missing or mismatched VS/PS bytecode, failed GLSL/SPIR-V compile/link.
- Missing per-stage float validity masks or mismatches between emitted write events, raw values and masks; shader-used float/BOOL register not proven set (except shader-local `DEFB`); incomplete/unsupported stream-source frequency state, multi-instance draws.
- Missing active sampler DDS snapshot, unsupported pixel sampler type/state/address/filter/sRGB/border, unsupported multi-mip filtering; missing/unsupported render states. Required render state IDs: `7,14,23,27,19,20,22,168,171,206`; full color-write mask `168=0xF`; when separate alpha enabled `206=1`, states `207,208` required. Sampler state IDs per active register: `1,2,5,6,7`.
- Missing/unsupported render target or depth format, mismatched color/depth dimensions, missing viewport, or missing Color+Depth Clear. **Critical provenance gap:** P1 packet includes only *last Clear values*, **not** the target identity and ordering at Clear time. Current P1 adapter invents a `clear` event anchored to the target bound at the draw. That synthetic association must **not** count as evidence of a valid retail clear. Later #2141 head emits `guest_packet_last_clear_unproven_target=true`, `last_clear_target_proven=false`, and its guarded builder rejects with the exact message `P1 packet last_clear has no target identity or ordering proof; refusing synthetic clear`. See [specific regression](https://github.com/Hanz0Hatt0r1/nfs-shift-decompilation/blob/9d9db201dd677f2f8d3eb811a6d475c8e176222a/tests/test_vulkan_d3d9_capture_bundle.py#L76-L97).

The guarded #2141 builder is an **admission oracle for this review**, but it is *not identical* to the current P1-branch builder, which lacks the explicit unproven-target rejection. A green output obtained solely by current P1's synthetic Clear path **is not proof of an admissible first retail replay**. If provenance is absent, the correct result is an explicit P1 producer missing-evidence handoff, **not** changing a flag or spoofing a Clear in P2.

Merged #2139 proves native Vulkan execution of a *separate* external retail capture with complete observed state, not that a P1 packet exists or that P1's synthetic Clear can be replayed. Neither an offline serializer success, `forward_draw==true` with null downstream, nor `validation_errors=0` from unrelated host frame submissions establishes retail guest drawing.

## 4. One minimal local acceptance check for the **first real** guest packet

**Precondition:** P1 has independently recorded an actual DIP callback on the integrated P-code runtime, with the unmodified retail PE and guest API semantics. Set nonempty `SHIFT_D3D9_PACKET_CAPTURE_DIR` *before* launch; keep the produced single-draw directory intact; do not substitute a synthetic packet for this admission check. The packet writer can be independently preflighted with the existing headless CTest `shift_vulkan_d3d9_packet_capture_adapter` (CMake target `shift_vulkan_d3d9_packet_capture_check`; source `native_vulkan/tests/d3d9_packet_capture_adapter_check.cpp`), but that fixture is **not** the requested real-packet acceptance result.

Run **one staged local capture→guarded-bundle→native-executor check**, with `$CAPTURE_JSONL` pointing to the **actual** `draw_<device>_<sequence>/capture.jsonl`, `$DRAW_EVENT_INDEX` taken verbatim from its `draw_indexed_primitive.event_index`, `$BUNDLE_DIR` a new output directory, and `$EXECUTOR` the locally built existing `shift_vulkan_bundle_execute`. The Python builder must be taken from the **guarded #2141 head**, using the matching repository sources; do **not** silently use the older P1-branch builder.

```bash
python src/render/vulkan/vulkan_d3d9_capture_bundle.py \
  "$CAPTURE_JSONL" "$DRAW_EVENT_INDEX" "$BUNDLE_DIR" &&
"$EXECUTOR" "$BUNDLE_DIR" "$BUNDLE_DIR/output.ppm" --validation
```

**Pass** only if: (a) P1 trace proves guest DIP entry→handler→P2 callback and all actual packet bytes/identity, (b) `capture.jsonl` plus required `buffers/*.bin` and `textures/*.dds` are independently present, (c) guarded builder produces `native_submission_gate.json` with `ready=true`, correct provenance and SHA-256 of capture/resources, and (d) executor submits the draw and reports `validation_errors=0`. No claim of original retail frame/image parity.

**Expected bounded failure on current packet-v1** (if no stronger producer evidence exists): guarded builder reports last Clear target/time not proven and **refuses the bundle**. This is a *valid, actionable negative acceptance result*, not a P2 Vulkan translation failure. Keep the original packet and exact error intact. If instead adapter itself fails, classify by its exact `error` (missing binding, unknown buffer history, invalid mip, etc.) and stop before bundle. If builder fails only after genuine resource/clear provenance is established, that specific failed predicate becomes a P2 renderer/bundle task.

## 5. Responsible owner and explicit limitations

**P1 ends** at generation of truthful, synchronous guest packet plus preceding callback resource history and producer-side provenance. P1 is responsible for reaching the real import, accurate lifetime/lock/discard and state snapshots, and for proving **which surface was actually cleared and when**; it must not falsely claim execution from host frames or counters.

**P2 begins** at `draw_indexed_primitive_callback` and offline capture writer, resource correctness checks, fail-closed bundle admission, shader and Vulkan translation, and real executor validation. P2 must not infer or synthesize unknown guest state to pass the gate.

**Open frontier:** v691 contains **no guest packet**. This report is static source review; no P1 runtime run, no local CTest, no native Vulkan execution, no code edits or new PR are claimed.
