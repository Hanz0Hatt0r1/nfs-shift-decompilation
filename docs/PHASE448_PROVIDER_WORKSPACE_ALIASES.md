# Phase 448 — specialized-provider packed workspace alias map

## Goal

Phase 448 makes the packed-address ambiguity in the specialized provider solver explicit.

For each provider, every hypothetical `(row, column)` pair in the `scalar_count × scalar_count` domain is mapped through `row_pointer[row] + 8*column` when the resulting address lies inside the factor workspace. Absolute addresses that correspond to multiple candidate pairs are emitted as collision classes.

## Retail-derived results

Provider 0 has 40 scalar rows and a 1190-double workspace. Enumerating all 1600 candidate row/column pairs produces 1190 unique storage addresses and 410 alias entries across 410 collision addresses.

Provider 1 has 34 scalar rows and a 746-double workspace. Enumerating all 1156 candidate pairs produces 746 unique storage addresses and 410 alias entries across 401 collision addresses.

The first provider-0 collision is the absolute address `0x00C21800`, which can be generated by `(row=0,column=25)` or `(row=1,column=0)` under the hypothetical full-domain mapping. Provider 1 begins similarly at `0x00C1FEE8`, generated by `(0,22)` and `(1,0)`.

These are address-space facts, not semantic ownership decisions.

## Consequence for reconstruction

A source assignment using an absolute `DAT_xxxxxxxx` address cannot automatically be translated into a unique logical matrix coordinate. Source context must decide which packed role is active at that point. This is the reason Phase 446 removed the adjacent-row segment length as a logical column bound.

The explicit pivot diagonal relation remains valid and is separately validated as an in-range workspace address:

    pivot_diagonal = row_pointer[i] + 8*i

## Scope boundary

The alias map deliberately does not decide logical ownership, sparse-matrix meaning, provider semantics, physical units, or BMW provider identity. It is a storage-ambiguity map used by later source-context reconstruction.

Run with:

    python specialized_provider_workspace_alias_runtime.py

or for one provider:

    python specialized_provider_workspace_alias_runtime.py --provider 0
