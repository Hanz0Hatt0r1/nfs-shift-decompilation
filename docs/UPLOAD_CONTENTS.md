# NFS SHIFT Decompilation — repository upload policy

## Keep

- clean-room source and neutral IR;
- format/runtime parsers;
- deterministic tests;
- capture/evidence tools;
- native build projects;
- compact non-redistributive fixtures;
- current documentation and historical phase records.

## Exclude

- original BFF/game distribution archives;
- proprietary resource payloads unless an intentionally small derived artifact is permitted;
- SHIFT.exe and full proprietary decompilation/source exports;
- large trace captures and bulk generated reports;
- build directories, binaries and machine-local caches.

## Evidence policy

Prefer hashes, provenance and compact derived observations over committing the original source material.

## Documentation policy

Current status documents must describe the actual mainline state. Historical successful test counts are not current baselines when CI is failing.
